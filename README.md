## AGFP — Aplicativo de Gerenciamento Financeiro Pessoal💰

(AGFP — Personal Financial Management App)

O AGFP é um aplicativo de gerenciamento financeiro pessoal desenvolvido como Trabalho de Conclusão de Curso (TCC), com o objetivo de ajudar as pessoas a controlarem suas finanças de forma simples e intuitiva.

O sistema permite organizar ganhos e gastos por categorias, além de apresentar gráficos e relatórios visuais que facilitam a compreensão do fluxo financeiro do usuário. 📊💵

##

🎯 Objetivo do Projeto | Project Goal

O principal propósito do AGFP é promover o controle financeiro pessoal de maneira acessível, prática e educativa — mostrando que gerenciar o dinheiro pode ser simples, mesmo para quem não tem experiência na área.

The main goal of AGFP is to promote personal financial control in an accessible, practical, and educational way — showing that managing money can be simple, even for those without prior financial experience.
##

💜 Desenvolvimento | Development

O projeto foi idealizado e construído como parte do Trabalho de Conclusão de Curso em Ciências da Computação, unindo conceitos de backend com Java Spring Boot e frontend mobile com React Native.

This project was conceived and built as part of a Computer Science graduation project (TCC), combining backend development with Java Spring Boot and mobile frontend with React Native.

##
💡 Sobre o Projeto | About the Project

O AGFP oferece uma interface simples e intuitiva, permitindo:

📂 Cadastro e categorização de receitas e despesas

📈 Visualização gráfica dos dados financeiros

💡 Análise rápida e simplificada do balanço mensal

Durante o desenvolvimento, o foco foi criar uma arquitetura sólida, com backend em Spring Boot responsável pelas regras de negócio e persistência de dados, e um aplicativo mobile em React Native com gráficos interativos e design responsivo.

AGFP provides a clean and intuitive interface that allows users to:

📂 Register and categorize income and expenses

📈 Visualize financial data through interactive charts

💡 Quickly analyze monthly balances and trends

The focus was to build a solid architecture, with a Spring Boot backend handling business logic and data persistence, and a React Native mobile app offering a responsive, dynamic, and user-friendly experience.
